# mod-world-journey

*简短版——完整说明见[英文 README](README.md)。*

一个面向只为 60 级设计的职业体系的 AzerothCore 模块——首先是 **Conquest of Azeroth**（CoA）的 21 个职业：整个世界——旧世界、外域和诺森德——成为一段从 1 到 60 级的旅程。

CoA 的职业止于 60 级。本模块不提高等级上限，而是压缩世界：旧世界的区域在 1 到 35 级开放，外域在 30 到 43 级，诺森德在 40 到 55 级，外域和诺森德的团队副本与英雄副本位于 60 级。由于 CoA 会把生物提升到角色等级，每个区域直到 60 级都值得一玩。物品、任务、专业、骑术、战场和机器人都跟随旅程；一切都可在 `mod_world_journey.conf` 中调整。

## 安装

最简单的方式是使用 [AFK Realm](https://github.com/aspollon/AFK-Realm)：在“模块 → 管理模块”中添加本模块，它会重新编译服务器并带上所需的一切；本模块的设置页面提供简体中文。不使用 AFK Realm：请参阅英文 README。

AFK Realm 显示的本模块文本已翻译在 `lang/` 中。

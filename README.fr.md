# mod-world-journey

*Version courte – la description complète se trouve dans le [README anglais](README.md).*

Un module AzerothCore pour les systèmes de classes faits pour le niveau 60 seulement – avant tout les 21 classes de **Conquest of Azeroth** (CoA) : le monde entier – ancien monde, Outreterre et Norfendre – comme un seul voyage de 1 à 60.

Les classes de CoA s’arrêtent à 60. Au lieu de relever le niveau maximal, le module comprime le monde : les zones de l’ancien monde s’ouvrent de 1 à 35, celles de l’Outreterre de 30 à 43, celles du Norfendre de 40 à 55, raids et héroïques de l’Outreterre et du Norfendre sont au niveau 60. Chaque zone reste intéressante jusqu’à 60, car CoA relève ses créatures au niveau du personnage. Objets, quêtes, métiers, monte, champs de bataille et bots suivent le voyage ; tout se règle dans `mod_world_journey.conf`.

## Installation

Le plus simple avec [AFK Realm](https://github.com/aspollon/AFK-Realm) : *Modules → Gérer les modules* ajoute le module, recompile le serveur et apporte tout le nécessaire ; la page de configuration du module est en français. Sans AFK Realm : voir le README anglais.

Les textes qu’AFK Realm affiche de ce module sont traduits dans `lang/`.
